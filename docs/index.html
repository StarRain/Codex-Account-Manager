首次打开提示无法验证开发者？+

发行包使用临时签名，尚未经过 Apple 开发者签名或公证。确认安装包来源可信后，先尝试打开应用，再到“系统设置 → 隐私与安全性”中选择“仍要打开”。

也可以在将 CAM 拖入“应用程序”后，在终端运行：

xattr -dr com.apple.quarantine "/Applications/Codex Account Manager.app"

该命令会移除应用的下载隔离标记，跳过相应的首次来源检查；它不会为应用补上签名或公证。查看 Apple 说明

账号和 API Key 可以同时使用吗？+

CAM 可以保存多种配置，但 Codex 在同一时刻使用其中一种登录方式。切换前 CAM 会备份当前文件凭据；请先结束其他 Codex CLI 会话。

为什么看不到 API Key 的余额？+

API Key 的计费与 ChatGPT 额度分开。CAM 显示 Codex 返回的账号额度，不显示 API Key 余额。

需要什么系统和运行环境？+

需要 macOS 13 或更高版本，以及已安装的 Codex CLI。发行包支持 Apple 芯片与 Intel Mac。
