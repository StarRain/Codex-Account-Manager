Questions? Visit GitHub
Can’t open the app because the developer cannot be verified?+

The download uses an ad-hoc signature and is not Apple developer-signed or notarized. After confirming the download is from a trusted source, try to open the app, then select “Open Anyway” in System Settings → Privacy & Security.

Alternatively, after dragging CAM to Applications, run this in Terminal:

xattr -dr com.apple.quarantine "/Applications/Codex Account Manager.app"

This removes the app’s download quarantine flag and skips the corresponding first-launch origin check. It does not add an Apple developer signature or notarization. Read Apple’s guidance

Can I use an account and an API key at the same time?+

CAM can save multiple configurations, but Codex uses one login method at a time. CAM backs up the current file credentials before switching; end other Codex CLI sessions first.

Why can’t I see an API key balance?+

API key billing is separate from ChatGPT usage. CAM shows account limits returned by Codex; it does not display API key balances.

What are the system requirements?+

You need macOS 13 or later and the Codex CLI. The download supports both Apple silicon and Intel Macs.
